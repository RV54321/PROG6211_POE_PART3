--------------------READ ME-----------------------

Steps for using the Program:

1.Open Visual Studio.

2.Open Project inside of Visual Studio.

3.Run project by clicking on the green play button.

4.When the console box appears, it will ask you to enter some information regarding income and expenses, enter this information and hit enter after each entry and fill in 
  the data that the program asks you for.

5.The program will ask you to purchase or rent, select the option you want by typing 'BUY' or 'RENT'.

6.Depedending on 'BUY' or 'RENT' you will have to enter specifioc information.

7.The program will ask if you want to purchase a vechile or not, if yes type 'PURCHASE' but if not type 'NOPURCHASE'.

8. If you decide to purchase a vehicle, please enter the information prompted by the program relating to vehicle financing.

9. The program will not display your monthly expenses in Descending order of cost and output how much money you have left after the end of each month.

10.You can now close the console window.
